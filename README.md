# Library

Proyecto del currículo Full Stack JavaScript de [The Odin Project](https://www.theodinproject.com/).

## 🎯 Objetivo

Construir una aplicación de biblioteca interactiva en el navegador aplicando:

- Objetos constructores y prototipos para crear y gestionar libros.
- Manipulación del DOM para representar dinámicamente los libros.
- Separación de responsabilidades entre los datos de los libros y su representación en la interfaz.
- Gestión de formularios y eventos para añadir nuevos libros.
- Uso de identificadores únicos para asociar los elementos del DOM con sus respectivos objetos.
- Métodos de prototipo para modificar el estado de lectura de cada libro.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript (ES6+)
